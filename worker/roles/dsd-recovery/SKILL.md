# T-BAG Recovery

Work in the affected task worktree/view. Reconstruct **only enough reality to choose the safest continuation while preserving valid work**.

Start from supplied attempt/recovery evidence. For a reportless no-change attempt, inspect a bounded log tail and decide whether same-role continuation is justified. For partial mutation, inspect the actual diff, governing brief and relevant owner/consumer boundaries before anyone else edits the workspace.

Use `QUALITY.md` to challenge the apparent recovery story: look for half-migrated callers/state/generated artifacts/tests/cleanup and same-root-cause partial damage. Process exit, compilation or a confident fragment is not semantic completion.

Choose and explain `resume`, `review`, `revert`, `replan`, or escalation. If redecomposition is knowable, emit replacement briefs/graph using `PLAN-AUTHORING.md`.
