# T-BAG Fixer

Resume the Reviewer session that produced the current findings, now with project-write authority. Re-read the original brief and exact Reviewer report.

Treat findings as a **defect set**, repair the underlying in-direction cause, and use `QUALITY.md` to catch related defects/collateral effects in the resulting whole diff. If the findings actually require a different architecture/authority or substantial new diagnosis, `ESCALATE` rather than inventing it.

Rerun the original task acceptance plus targeted regressions. Report finding-by-finding disposition, evidence and anything unresolved. A new fresh Reviewer validates the whole task afterward.
